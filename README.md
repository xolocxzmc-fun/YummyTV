# Yummy TV

Неофициальное приложение для Android TV (в том числе для телевизоров и приставок Xiaomi), чтобы смотреть аниме с [YummyAnime](https://old.yummyani.me) с пульта: без курсора и мыши, с выбором озвучки и плеера.

Каталог, поиск, расписание и данные об аниме берутся из официального API сайта (`api.yani.tv`). Видео показывают плееры сайта (Kodik, Alloha, CVH), как и на самом сайте.

## Возможности

- **Главная:** «Продолжить просмотр», избранное, новые серии, популярное за сезон, недавно добавленные, анонсы и подборки.
- **Поиск:** экранная клавиатура (РУС / EN / 123), голосовой поиск с пульта, ввод с подключённой клавиатуры.
- **Каталог:** сортировка (популярные, рейтинг, топ-100, новые, по названию, случайные), фильтры по типу, статусу, жанрам и году.
- **Расписание** выхода серий по дням.
- **Страница аниме:** рейтинги (сайт, Shikimori, MAL, Кинопоиск), описание, трейлер, порядок просмотра, похожие, избранное.
- **Озвучка и плеер:** выбор из всех доступных. Приложение запоминает выбор для каждого аниме, а последнюю выбранную озвучку предлагает и для новых.
- **Серии:** отметки просмотренного, полоса прогресса, переход по диапазонам для длинных сериалов.
- **Плеер:**
  - пауза и перемотка с ускорением, если зажать стрелку;
  - продолжение с места остановки;
  - кнопка «Пропустить опенинг» и автоматический пропуск опенинга;
  - автопереход на следующую серию с отсчётом;
  - смена озвучки, плеера или качества (1080p / 720p / 480p / 360p) прямо во время просмотра: серия продолжится с той же секунды;
  - интерфейс встроенного плеера скрыт: на паузе видна только картинка, всё управление своё.
- **Блокировка рекламы** в плеерах: рекламные и трекинговые запросы блокируются, всплывающие окна запрещены. Отключается в настройках.
- **История и избранное** хранятся на телевизоре.

## Скорость и надёжность

- **Мгновенный старт.** Последние данные (главная, страницы аниме, расписание, каталог) хранятся на телевизоре. Приложение открывается сразу и обновляет их в фоне, не сбивая фокус.
- **Предзагрузка.** Если задержать фокус на карточке на полсекунды, её страница загружается заранее и открывается мгновенно. Название и описание вообще показываются сразу, догружаются только серии.
- **Сеть.** У каждого запроса есть таймаут и повторы. Если сервер долго не отвечает, на экране появится понятное сообщение и кнопка «Повторить», а не вечная загрузка.
- **Плеер.**
  - Пока видео не стартовало, приложение несколько раз повторяет команду запуска.
  - При подгрузке видео показывается индикатор.
  - Если видео остановилось, приложение пробует продолжить и подсказывает сменить плеер.
  - Сообщения от предыдущей серии игнорируются, так что быстрое переключение серий не путает состояние.
- **Память.**
  - В памяти живут максимум 4 экрана: при длинных цепочках «аниме → похожее → …» старые экраны выгружаются и восстанавливаются из кэша по «Назад».
  - Сохранённых ответов не больше 80, и они не старше 14 дней.
  - Дисковый кэш WebView больше 300 МБ очищается при запуске.
  - При нехватке памяти внутренние кэши сбрасываются.
- **Без вылетов.**
  - Если Android убьёт движок WebView (бывает на ТВ с малым объёмом памяти), приложение пересоздаст его, а не закроется.
  - Ошибка в одном обработчике не блокирует пульт.
  - Если зажать кнопку, лишние повторы отбрасываются, и после отпускания ничего не «доезжает».

## Управление с пульта

| Где | Кнопка | Действие |
|---|---|---|
| Везде | Стрелки | Перемещение |
| Везде | OK | Выбрать |
| Везде | Назад | На шаг назад; на главной — двойное нажатие для выхода |
| Карточка аниме | Меню | Открыть описание (на «Продолжить просмотр» OK сразу запускает серию) |
| Плеер | OK | Пауза / продолжить (или «Пропустить опенинг», когда кнопка видна) |
| Плеер | ← → | Перемотка на 10 с; если зажать — на 30 и 60 с |
| Плеер | ↓ (или ↑, Меню) | Нижняя панель как в YouTube: полоса перемотки, пауза, пред./след. серия, серии, озвучка, плеер, качество, «Ещё» |
| Панель | ← → / OK / Назад | Выбор кнопки / открыть ряд вариантов / закрыть |
| Плеер | CH+ / CH− или ⏭ / ⏮ | Следующая / предыдущая серия |

## Как получить APK (GitHub, без программирования)

**1. Создайте репозиторий.** Зайдите на github.com → кнопка **+** вверху справа → **New repository**.
Название: `YummyTV`. Выберите **Private**. Галочки «Add a README» и прочие не ставьте. Нажмите **Create repository**.

**2. Загрузите файлы.** На странице пустого репозитория нажмите ссылку **uploading an existing file**.
- В Finder откройте папку проекта и нажмите **Cmd + Shift + .** (точка): так станет видна скрытая папка `.github`, без неё сборка не запустится.
- Выделите всё содержимое папки (Cmd + A) и перетащите в окно браузера.
- Внизу нажмите **Commit changes**.

**3. Дождитесь сборки.** Откройте вкладку **Actions**: там появится задача «Build APK».
- Через 3–6 минут у неё появится зелёная галочка.
- Если появился красный крестик, откройте задачу и пришлите мне скриншот ошибки, я поправлю.

**4. Скачайте APK.** На главной странице репозитория справа есть блок **Releases**. Откройте последнюю версию и скачайте `YummyTV-1.0.N.apk`.

Каждая следующая загрузка изменений (снова «Add file → Upload files») автоматически собирает новую версию. Её можно ставить поверх старой: история и избранное сохранятся, потому что APK всегда подписывается одним ключом из `keystore/`.

> Пароль ключа подписи лежит в `app/build.gradle.kts`, поэтому репозиторий держите приватным.

Если удобнее через терминал:
```bash
cd ~/Documents/FUN/ANIMУ
git init && git add . && git commit -m "Yummy TV"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/YummyTV.git
git push -u origin main
```

## Установка на телевизор Xiaomi

**1. Разрешите установку APK.**
- На телевизорах с PatchWall / Android TV: **Настройки → Настройки устройства → Безопасность и ограничения → Неизвестные источники**.
- На Google TV: **Настройки → Конфиденциальность → Безопасность и ограничения → Неизвестные источники**.

Включите переключатель для приложения, через которое будете ставить APK (файловый менеджер или Send Files to TV).

**2. Перенесите APK** одним из способов:
- **Send Files to TV:** поставьте приложение из Google Play на телефон и на ТВ, отправьте файл по Wi‑Fi.
- **Флешка:** скопируйте APK, вставьте флешку в ТВ, откройте файл в файловом менеджере («Файлы», X‑plore или File Commander) и нажмите «Установить».

**3. Закрепите на главном экране.** Yummy TV появится в списке приложений. Наведите на плитку, удерживайте OK и выберите «Переместить» или «Добавить в избранное», чтобы поставить её в первый ряд.

Если видео не запускается или плеер работает плохо, обновите **Android System WebView** (или Google Chrome) в Google Play на телевизоре. Приложение работает поверх него.

### Иконка и баннер

Ресурсы сделаны по [правилам Google для иконок TV-приложений](https://developer.android.com/design/ui/tv/guides/system/tv-app-icon-guidelines). Им следуют Android TV, Google TV и Xiaomi PatchWall.
- **Баннер 16:9** с логотипом и названием, во всех плотностях от 160×90 до 640×360 (`mipmap-*/banner.png`). Это главная плитка в ряду приложений.
- **Иконка** в «телевизионных» размерах от 80×80 до 320×320, плюс адаптивная версия для Android 8+: фон и логотип отдельными слоями, логотип внутри безопасной зоны.

Всё генерируется из логотипа сайта командой `python tools/make_icons.py`.

## Если что-то не работает

- **Видео не стартует.** Нажмите OK ещё раз или откройте ↑ → «Ещё» → «Нажать Play внутри плеера» / «Перезагрузить плеер».
- **Плеер тормозит или выдаёт ошибку.** ↑ → «Плеер» → выберите другой (Kodik / Alloha / CVH). Серия продолжится с того же места.
- **Плеер просит что-то нажать из-за рекламы.** Выключите «Блокировать рекламу» в настройках.
- **Мелкий или крупный текст.** Настройки → «Размер интерфейса».
- **Слабый телевизор.** Настройки → выключите «Анимации и плавная прокрутка».

## Устройство проекта

```
app/src/main/java/tv/yummy/client/
  MainActivity.kt   WebView, пульт → JavaScript, голосовой поиск, жизненный цикл
  AdBlocker.kt      блокировка рекламы и трекеров на уровне запросов
app/src/main/assets/web/
  index.html, app.css, app.js   интерфейс (без фреймворков, ES2017 для старых WebView)
  inject.js         управление видео внутри плееров (пауза, перемотка, статус)
tools/preview/      превью интерфейса в браузере на тестовых данных (Playwright)
.github/workflows/build.yml     сборка APK
```

Интерфейс открывается по адресу `https://old.yummyani.me/tvapp/` и отдаётся из файлов приложения, без сети. Поэтому плееры сайта работают в нём так же, как на самом сайте.

**Тесты без телевизора** (`pip install playwright`, нужен ffmpeg):
- `python tools/preview/run.py shots` — скриншоты всех экранов и сквозной сценарий плеера;
- `python tools/preview/scenarios.py` — каверзные сценарии: быстрое переключение серий, выход посреди загрузки, смена озвучки, длинные цепочки, «шторм» кнопки «Назад»;
- `python tools/preview/monkey.py 1500 1` — тысячи случайных нажатий при нестабильной сети с проверкой после каждого шага;
- `python tools/preview/perf.py` — скорость на «слабом ТВ» (процессор в 6 раз медленнее, сеть +2 с).

**Превью без телевизора:** `pip install playwright`, затем `python tools/preview/run.py shots`. Нужен ffmpeg. Скриншоты экранов сохранятся в `tools/preview/shots/`.
